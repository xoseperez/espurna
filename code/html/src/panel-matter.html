MATTER

Matter On/Off plug on relay #0, with the device certificates the board came with

Status
Off: Matter only starts with the button below (or matter.start in the terminal), a crash then does not repeat on every boot.
Pairing
Add the device in a Matter controller on the same network (pairing over IP, this firmware has no Bluetooth). The code contains the device setup PIN: show it only to people who may control the device.
The window closes 15 minutes after the start and after a controller added the device. Open it again to pair once more or to add a second controller.
