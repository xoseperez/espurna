A Matter On/Off plug for every relay, with the device certificates the board came with

Status
On 2 MiB Tuya boards the firmware keeps its Matter code apart: it comes with a second upload of the same file, which has not happened yet, so Matter cannot start. Install the Matter code takes the newest release of this image from GitHub (a newer release updates the firmware too, the board restarts once or twice). Or upload the same espurna-beken-matter.bin once more in ADMIN, Upgrade.
    Off: Matter only starts with the button below (or matter.start in the terminal), a crash then does not repeat on every boot.
    Controllers
    Apps and hubs this device was added to. Deleting the device in an app does not always reach the device (the hub's phone app does not tell it): the old entry stays here, and adding the device to the same app again fails until it is removed.
    Pairing
    Add the device in a Matter controller on the same network (pairing over IP, this firmware has no Bluetooth). Adding it again to an app that had it before? Remove the app above first. The code contains the device setup PIN: show it only to people who may control the device.
    The window closes 15 minutes after the start and after a controller added the device. Open it again to pair once more or to add a second controller.
