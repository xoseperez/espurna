Tasmota Profile Import
Paste a Tasmota device template JSON to automatically configure relays, buttons and LEDs. GPIO function codes will be mapped to ESPurna settings.
Switch inputs are AC mains wall switches connected through an optocoupler (frequency detection). Tasmota templates cannot express this, in Tasmota it is enabled with SwitchDebounce ending with 9. Inputs imported from Switch codes become ESPurna buttons in switch mode with AC detection, 100 ms debounce and relay toggle on every position change, controlling the relay with the same number (like Tasmota Switch1 → Relay1).
Also treat inputs imported from Button codes as AC mains switches. Some templates use Button codes for the wall switch inputs.
Optional. When SwitchDebounce ending with 9 is found here, AC mains switches option is enabled automatically.
